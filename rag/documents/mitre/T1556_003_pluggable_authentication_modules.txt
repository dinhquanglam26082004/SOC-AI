T1556.003 - Pluggable Authentication Modules

Tactic: Defense Impairment, Persistence, Credential Access
Platform: linux, macos

Description:
Adversaries may modify pluggable authentication modules (PAM) to access user
credentials or enable otherwise unwarranted access to accounts. PAM is a
modular system of configuration files, libraries, and executable files which
guide authentication for many services. The most common authentication module
is <code>pam_unix.so</code>, which retrieves, sets, and verifies account
authentication information in <code>/etc/passwd</code> and
<code>/etc/shadow</code>.  Adversaries may modify components of the PAM system
to create backdoors. PAM components, such as <code>pam_unix.so</code>, can be
patched to accept arbitrary adversary supplied values as legitimate
credentials.  Malicious modifications to the PAM system may also be abused to
steal credentials. Adversaries may infect PAM resources with code to harvest
user credentials, since the values exchanged with PAM components may be plain-
text since PAM does not store passwords.

Detection:
Monitor for anomalous behavior related to this technique.

Mitigation:
  - Privileged Account Management
  - Multi-factor Authentication
