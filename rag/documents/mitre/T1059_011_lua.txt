T1059.011 - Lua

Tactic: Execution
Platform: linux, macos, network devices, windows

Description:
Adversaries may abuse Lua commands and scripts for execution. Lua is a cross-
platform scripting and programming language primarily designed for embedded
use in applications. Lua can be executed on the command-line (through the
stand-alone lua interpreter), via scripts (<code>.lua</code>), or from Lua-
embedded programs (through the <code>struct lua_State</code>).  Lua scripts
may be executed by adversaries for malicious purposes. Adversaries may
incorporate, abuse, or replace existing Lua interpreters to allow for
malicious Lua command execution at runtime.

Detection:
Monitor for anomalous behavior related to this technique.

Mitigation:
  - Limit Software Installation
  - Execution Prevention
  - Audit
