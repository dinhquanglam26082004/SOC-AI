T1518 - Software Discovery

Tactic: Discovery
Platform: esxi, iaas, linux, macos, windows

Description:
Adversaries may attempt to get a listing of software and software versions
that are installed on a system or in a cloud environment. Adversaries may use
the information from Software Discovery during automated discovery to shape
follow-on behaviors, including whether or not the adversary fully infects the
target and/or attempts specific actions.  Such software may be deployed widely
across the environment for configuration management or security reasons, such
as Software Deployment Tools, and may allow adversaries broad access to infect
devices or move laterally.  Adversaries may attempt to enumerate software for
a variety of reasons, such as figuring out what security measures are present
or if the compromised system has a version of software that is vulnerable to
Exploitation for Privilege Escalation.

Sub-techniques:
  T1518.002 - Backup Software Discovery
  T1518.001 - Security Software Discovery

Detection:
Monitor for anomalous behavior related to this technique.

Mitigation:
  - Follow vendor hardening guidelines.
  - Apply least-privilege principle.
