T1552 - Unsecured Credentials

Tactic: Credential Access
Platform: containers, iaas, identity provider, linux, macos, network devices, office suite, saas, windows

Description:
Adversaries may search compromised systems to find and obtain insecurely
stored credentials. These credentials can be stored and/or misplaced in many
locations on a system, including plaintext files (e.g. Shell History),
operating system or application-specific repositories (e.g. Credentials in
Registry),  or other specialized files/artifacts (e.g. Private Keys).

Sub-techniques:
  T1552.005 - Cloud Instance Metadata API
  T1552.002 - Credentials in Registry
  T1552.004 - Private Keys
  T1552.003 - Shell History
  T1552.001 - Credentials In Files
  T1552.006 - Group Policy Preferences
  T1552.008 - Chat Messages
  T1552.007 - Container API

Detection:
Monitor for anomalous behavior related to this technique.

Mitigation:
  - Limit Access to Resource Over Network
  - Filter Network Traffic
  - User Training
  - Operating System Configuration
  - Password Policies
  - Restrict File and Directory Permissions
  - Privileged Account Management
  - Audit
  - Active Directory Configuration
  - Update Software
  - Encrypt Sensitive Information
