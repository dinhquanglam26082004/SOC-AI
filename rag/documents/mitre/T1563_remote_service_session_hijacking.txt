T1563 - Remote Service Session Hijacking

Tactic: Lateral Movement
Platform: linux, macos, windows

Description:
Adversaries may take control of preexisting sessions with remote services to
move laterally in an environment. Users may use valid credentials to log into
a service specifically designed to accept remote connections, such as telnet,
SSH, and RDP. When a user logs into a service, a session will be established
that will allow them to maintain a continuous interaction with that service.
Adversaries may commandeer these sessions to carry out actions on remote
systems. Remote Service Session Hijacking differs from use of Remote Services
because it hijacks an existing session rather than creating a new session
using Valid Accounts.

Sub-techniques:
  T1563.001 - SSH Hijacking
  T1563.002 - RDP Hijacking

Detection:
Monitor for anomalous behavior related to this technique.

Mitigation:
  - Network Segmentation
  - Password Policies
  - User Account Management
  - Privileged Account Management
  - Disable or Remove Feature or Program
