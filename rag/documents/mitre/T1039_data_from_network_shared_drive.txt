T1039 - Data from Network Shared Drive

Tactic: Collection
Platform: linux, macos, windows

Description:
Adversaries may search network shares on computers they have compromised to
find files of interest. Sensitive data can be collected from remote systems
via shared network drives (host shared directory, network file server, etc.)
that are accessible from the current system prior to Exfiltration. Interactive
command shells may be in use, and common functionality within cmd may be used
to gather information.

Detection:
Monitor for anomalous behavior related to this technique.

Mitigation:
  - Follow vendor hardening guidelines.
  - Apply least-privilege principle.
