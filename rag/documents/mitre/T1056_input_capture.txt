T1056 - Input Capture

Tactic: Collection, Credential Access
Platform: linux, macos, network devices, windows

Description:
Adversaries may use methods of capturing user input to obtain credentials or
collect information. During normal system usage, users often provide
credentials to various different locations, such as login pages/portals or
system dialog boxes. Input capture mechanisms may be transparent to the user
(e.g. Credential API Hooking) or rely on deceiving the user into providing
input into what they believe to be a genuine service (e.g. Web Portal
Capture).

Sub-techniques:
  T1056.001 - Keylogging
  T1056.003 - Web Portal Capture
  T1056.002 - GUI Input Capture
  T1056.004 - Credential API Hooking

Detection:
Monitor for anomalous behavior related to this technique.

Mitigation:
  - Follow vendor hardening guidelines.
  - Apply least-privilege principle.
