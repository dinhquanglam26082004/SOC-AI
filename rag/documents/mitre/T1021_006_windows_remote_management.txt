T1021.006 - Windows Remote Management

Tactic: Lateral Movement
Platform: windows

Description:
Adversaries may use Valid Accounts to interact with remote systems using
Windows Remote Management (WinRM). The adversary may then perform actions as
the logged-on user.  WinRM is the name of both a Windows service and a
protocol that allows a user to interact with a remote system (e.g., run an
executable, modify the Registry, modify services). It may be called with the
`winrm` command or by any number of programs such as PowerShell. WinRM  can be
used as a method of remotely interacting with Windows Management
Instrumentation.

Detection:
Monitor for anomalous behavior related to this technique.

Mitigation:
  - Network Segmentation
  - Privileged Account Management
  - Disable or Remove Feature or Program
