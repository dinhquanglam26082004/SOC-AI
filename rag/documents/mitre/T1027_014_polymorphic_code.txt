T1027.014 - Polymorphic Code

Tactic: Stealth
Platform: linux, macos, windows

Description:
Adversaries may utilize polymorphic code (also known as metamorphic or
mutating code) to evade detection. Polymorphic code is a type of software
capable of changing its runtime footprint during code execution. With each
execution of the software, the code is mutated into a different version of
itself that achieves the same purpose or objective as the original. This
functionality enables the malware to evade traditional signature-based
defenses, such as antivirus and antimalware tools.  Other obfuscation
techniques can be used in conjunction with polymorphic code to accomplish the
intended effects, including using mutation engines to conduct actions such as
Software Packing, Command Obfuscation, or Encrypted/Encoded File.

Detection:
Monitor for anomalous behavior related to this technique.

Mitigation:
  - Behavior Prevention on Endpoint
  - Antivirus/Antimalware
