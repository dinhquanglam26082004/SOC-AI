T1030 - Data Transfer Size Limits

Tactic: Exfiltration
Platform: esxi, linux, macos, windows

Description:
An adversary may exfiltrate data in fixed size chunks instead of whole files
or limit packet sizes below certain thresholds. This approach may be used to
avoid triggering network data transfer threshold alerts.

Detection:
Monitor for anomalous behavior related to this technique.

Mitigation:
  - Network Intrusion Prevention
