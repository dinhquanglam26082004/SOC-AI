T1567 - Exfiltration Over Web Service

Tactic: Exfiltration
Platform: esxi, linux, macos, office suite, saas, windows

Description:
Adversaries may use an existing, legitimate external Web service to exfiltrate
data rather than their primary command and control channel. Popular Web
services acting as an exfiltration mechanism may give a significant amount of
cover due to the likelihood that hosts within a network are already
communicating with them prior to compromise. Firewall rules may also already
exist to permit traffic to these services.  Web service providers also
commonly use SSL/TLS encryption, giving adversaries an added level of
protection.

Sub-techniques:
  T1567.004 - Exfiltration Over Webhook
  T1567.001 - Exfiltration to Code Repository
  T1567.003 - Exfiltration to Text Storage Sites
  T1567.002 - Exfiltration to Cloud Storage

Detection:
Monitor for anomalous behavior related to this technique.

Mitigation:
  - Restrict Web-Based Content
  - Data Loss Prevention
