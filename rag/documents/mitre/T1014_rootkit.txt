T1014 - Rootkit

Tactic: Stealth
Platform: linux, macos, windows

Description:
Adversaries may use rootkits to hide the presence of programs, files, network
connections, services, drivers, and other system components. Rootkits are
programs that hide the existence of malware by intercepting/hooking and
modifying operating system API calls that supply system information.
Rootkits or rootkit enabling functionality may reside at the user or kernel
level in the operating system or lower, to include a hypervisor or System
Firmware.  Rootkits have been seen for Windows, Linux, and Mac OS X systems.
Rootkits that reside or modify boot sectors are known as Bootkits and
specifically target the boot process of the operating system.

Detection:
Monitor for anomalous behavior related to this technique.

Mitigation:
  - Follow vendor hardening guidelines.
  - Apply least-privilege principle.
