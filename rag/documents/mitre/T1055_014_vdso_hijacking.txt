T1055.014 - VDSO Hijacking

Tactic: Stealth, Privilege Escalation
Platform: linux

Description:
Adversaries may inject malicious code into processes via VDSO hijacking in
order to evade process-based defenses as well as possibly elevate privileges.
Virtual dynamic shared object (vdso) hijacking is a method of executing
arbitrary code in the address space of a separate live process.   VDSO
hijacking involves redirecting calls to dynamically linked shared libraries.
Memory protections may prevent writing executable code to a process via Ptrace
System Calls. However, an adversary may hijack the syscall interface code
stubs mapped into a process from the vdso shared object to execute syscalls to
open and map a malicious shared object. This code can then be invoked by
redirecting the execution flow of the process via patched memory address
references stored in a process' global offset table (which store absolute
addresses of mapped library functions).  Running code in the context of
another process may allow access to the process's memory, system/network
resources, and possibly elevated privileges. Execution via VDSO hijacking may
also evade detection from security products since the execution is masked
under a legitimate process.

Detection:
Monitor for anomalous behavior related to this technique.

Mitigation:
  - Behavior Prevention on Endpoint
