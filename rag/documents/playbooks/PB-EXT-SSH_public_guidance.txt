PLAYBOOK ID: PB-EXT-SSH
NAME: SSH brute force and password guessing investigation
Provenance: Curated paraphrase of MITRE ATT&CK T1110.001, https://attack.mitre.org/techniques/T1110/001/ . Reviewed 2026-11-02. Guidance only; not observed incident evidence.
Password guessing repeatedly tests candidate passwords against account authentication. It must be distinguished from offline password cracking, password spraying and credential stuffing.
Local application guidance: query search_auth_events for the affected agent and incident window. Group observations by exact source IP and username, and preserve event order. Inspect failures and subsequent successes; failures followed by success do not prove account compromise or attacker identity. Check authorization and follow-on activity independently. SSH network connections alone cannot reveal credentials or prove authentication success. sudo failures are not SSH login failures. Missing authentication logs are a coverage gap. Cite returned event IDs for factual claims; cite this document only as guidance. Suggested analyst actions: verify the account owner, examine authentication configuration and assess rate limiting or MFA without automatically locking legitimate users out.
